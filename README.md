# Our Family Recipe Book

A public, mobile-friendly collection of family recipes hosted free with GitHub Pages.

## What's included
- Searchable homepage with category filters.
- Individual recipe pages with ingredient lists and numbered instructions.
- Schema.org `Recipe` JSON-LD on each recipe page to help recipe apps recognize the recipe title, ingredients, yield, and instructions.
- Responsive layout for phones and computers.

## Edit the site
- `index.html` — homepage and recipe listings.
- `styles.css` — colors, layout, and mobile styling.
- `site.js` — search and category filtering.
- `recipes/` — individual recipe pages.

## Publish with GitHub Pages
The workflow at `.github/workflows/pages.yml` deploys the repository root whenever changes are pushed to `main`.

In the repository, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source if it is not already selected.

Expected site address: https://kmb1859.github.io/Recipe-Book/

## Recipe collection status
The first seven pages are a starter collection transcribed from existing meal-plan documents. More recipes from earlier conversations and files still need to be audited and added. Where source text was unclear, quantities have not been guessed.
